## Sobre o projeto
Este **Projeto Cadastro de Mangás** é uma aplicação fullstack desenvolvida como um teste de funcionalidade de funções no Git no curso de desenvolvimento de sistemas, oferecido pelo SENAI Sorocaba - Gaspar Ricardo Júnior, ministrado pelo Prof. [Vedilson Prado](https://github.com/vedilsonprado).O projeto **Cadastro Mangás** consiste no desenvolvimento de um site para facilitar o cadastro de mangás. Seu objetivo é organizar os dados de forma prática, deixando o gerenciamento e a visualização de suas conquistas de forma mais clara. O sistema possui as funções de cadastro de mangás, permitindo que todas as informações do mangá fiquem armazenadas em um único lugar. Dessa forma, a pessoa que o utilizar pode manter os registros organizados e facilitar a sua visualização. Além de atender às necessidades de organização, o projeto também tem como objetivo colocar em prática os conhecimentos adquiridos durante o curso, como o desenvolvimento de API RESTful, o uso de Banco de Dados Relacional, a integração entre o backend e o frontend utilizando JavaScript e a conexão utilizando o GitHub.

## Tecnologias utilizadas

### Backend
**Java 17** Principal linguagem.
    - **Spring Boot:** Framework para a criação de api

### Banco de Dados
**MySQL:** Banco de Dados Relacional.

### Frontend
**HTML5 & CSS3:** Estrutura semântica e estilização
**JavaScript:** Lógica do cliente e consumo da APi.

## Como executar o projeto

### 1. Banco de Dados
Crie o banco de dados MySQL executando o script SQL: 
CREATE DATABASE db_manga;
### 2. Backend
Clonar repositório.
Configure o arquivo application.properties com as suas credenciais do MySQL.
A API rodará em: hhtp://localhost:8080

### 3. Frontend
Navegue até a pasta do Frontend.
Acesse o index.html no navegador.
